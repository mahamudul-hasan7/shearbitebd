# Design System

## Brand

- Primary: deep sustainable green
- Accent: energetic orange
- Background: warm off-white
- Surface: clean white
- Text: dark green-black

## Component rules

- Card radius: 20–24px
- Inputs: minimum 48px height
- Mobile touch targets: minimum 44px
- Main actions: green gradient or solid brand green
- Orange is used for urgency, active navigation and emphasis
- Red is reserved for destructive actions and critical deadlines

## Accessibility

- Never communicate status using color alone.
- Pair badges with text and icons.
- Keep visible focus rings.
- Use semantic headings and form labels.
- Respect safe-area padding on mobile navigation.
